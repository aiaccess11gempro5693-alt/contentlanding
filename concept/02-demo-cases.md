# 02. Демо-кейсы

Проблема: реальных кейсов мало, часть под NDA (особенно тренажёры).
Решение — три источника кейсов, и у каждого честная пометка.

| Тип | Что это | Пометка на сайте |
|---|---|---|
| **Реальные** | Сделанные для клиентов работы, которые можно показывать | «Проект для клиента» |
| **Реальные обезличенные** | NDA-проекты: без логотипов, с изменёнными названиями, показываем механику и результат | «Проект под NDA, детали изменены» |
| **Концепт-кейсы** | Сделаны нами для демонстрации — на вымышленном бренде | «Концепт студии» |

Концепт-кейсы — это не «фейк», а сильный аргумент: «вот что наш конвейер
делает с одним брифом». Так делают многие студии.

---

## Главная идея: один бриф → весь комплект

Придумываем **один вымышленный бренд** и прогоняем его через весь конвейер.
На лендинге это становится сквозной историей: «Мы получили бриф в понедельник.
Вот что было готово к пятнице».

### Бренд для демо (рабочий вариант)

- **Категория:** безрецептурное средство или БАД для сна / от стресса.
  Почему: понятно любому человеку, красиво визуализируется (ночь, свет, спокойствие),
  нет рисков рекламы рецептурных препаратов, при этом звучит «по-фармовски».
- **Название:** придумать (рабочее — «Ноктис»). Проверить, что такого бренда нет.
- **Бриф:** запуск продукта в аптеках и на маркетплейсах + обучение сотрудников аптек.

### Что производим для этого бренда (по каталогу)

| Приоритет | Продукт | Номер в каталоге | Зачем на лендинге |
|---|---|---|---|
| 1 | Айдентика + упаковка | 1.2 | Начало истории |
| 1 | Ключевой визуал + 10–15 адаптаций | 1.1 | Показывает масштаб «один визуал → вся кампания» |
| 1 | 3D-упаковка, вращается на сайте | 4.1, 4.2 | Интерактив прямо на лендинге |
| 1 | Имиджевый ИИ-ролик 30 сек | 3.2 | Главное «вау» |
| 1 | Карточки маркетплейса | 1.4 | Понятный бизнес-результат |
| 1 | Тренажёр «Покупатель просит что-то для сна» | 6.2 или 6.3 | Закрывает вопрос «а игры/тренажёры мы делаем?» |
| 2 | Аватар-эксперт рассказывает о продукте | 5.3 | Вау + понятно, как экономит съёмки |
| 2 | Квиз / мини-игра | 6.4, 6.5 | Можно встроить в лендинг как интерактив |
| 2 | POS для аптеки | 1.5 | Мокапы в аптечной среде |
| 3 | Лендинг продукта | 7.1 | Можно показать скринкаст |
| 3 | ИИ-фотозона (демо) | 8.2 | Если будет время |

### Как превратить это в доказательство «2–4×»

Это главное: **цифру «2–4 раза» нельзя придумать, её нужно замерить.**

1. Для каждого демо-продукта фиксируем время: старт, этапы, финиш (в часах).
2. Рядом пишем, сколько это заняло бы «по-старому» — оценка команды или прошлые проекты.
3. Сохраняем промежуточные материалы: первые генерации, отбор, правки, финал.
   Это контент для блока «как мы работаем» — показать «кухню» конвейера.
4. На лендинге: таймлайн недели с реальными часами по каждому продукту.

## Реальные кейсы — что собрать у команды

Для каждого проекта, который можно показать (хотя бы обезличенно):

- что просил клиент (одна фраза);
- что сделали (продукты из каталога);
- сколько заняло времени и сколько заняло бы без ИИ;
- результат в цифрах, если есть (прохождение курса, рост знаний, продажи, экономия);
- 3–5 лучших кадров / видео / запись экрана интерактива;
- можно ли показывать логотип / название.

Отдельно — тренажёры: даже под NDA можно записать 20-секундный скринкаст
на изменённых данных. Это закроет вопрос «реальных кейсов нет».

---

## Минимум для встречи с Олегом

Не нужно делать всё сразу. Для концепции достаточно:

1. Лого + упаковка вымышленного бренда.
2. KV + 3–4 адаптации.
3. Одна 3D-модель упаковки.
4. 10–15 секунд ИИ-видео.
5. Прототип тренажёра на 3–4 шага диалога.

Пять материалов закрывают визуал, 3D, видео и обучение — и уже дают первые замеры времени.
