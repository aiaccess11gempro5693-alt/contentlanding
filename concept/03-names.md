# 03. Название студии

Критерии:

- связь с ЦентрФармой считывается, но не «аптечная»;
- передаёт скорость / технологию / производство;
- работает на русском и латиницей;
- коротко, легко произносится, есть свободный домен и нет зарегистрированного товарного знака (проверить в Роспатенте и на доменах до выбора).

Подпись везде одинаковая: **«студия ЦентрФармы»** / **«by CenterPharma»**.

## Варианты

| Название | Смысл | Как звучит в слогане |
|---|---|---|
| **Катализ / Catalyst** ⭐ | Катализатор ускоряет реакцию, не меняя результат. Ровно то, что ИИ делает с производством | «Ускоряем контент в 2–4 раза» |
| **Синтез / SYNTEZ** | Синтез — из простых элементов получается новое вещество. ИИ + люди → результат | «Синтезируем контент» |
| **Реактор** | Скорость, энергия, мощность | «Контент на реакторной тяге» |
| **ЦЕХ / CEH** | Прямо про «завод/конвейер» из идеи Олега | «Цех контента ЦентрФармы» |
| **Капсула / Capsule** | Упаковываем сложное в простое и готовое | «Вся кампания в одной капсуле» |
| **Formula Lab** | Отсылка к «формуле доверия» с текущего сайта + лаборатория | «Лаборатория контента» |
| **Molecula** | Контент из базовых элементов; фармовый оттенок | «Каждая деталь — молекула» |
| **Доза** | Точная доза контента: ровно сколько нужно | «Ваша доза контента» (смелее, более разговорно) |

## Рекомендация

**Катализ** — единственное название, которое само объясняет главный
аргумент (ИИ ускоряет), имеет фармовую химическую природу и не выглядит
узко аптечным. Слоган сразу: «Катализатор вашего контента».

Запасной — **ЦЕХ**: прямо ложится на метафору конвейера, но звучит проще.
