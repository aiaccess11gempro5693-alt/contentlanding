# Промпты для GPT: генерация интерфейсов

Два способа:
- **Картинки-макеты** (генерация изображений в ChatGPT) — быстро, много вариантов, удобно «набирать солянку». Минус: кириллица на картинках иногда ломается — просим крупный текст и мало слов.
- **Живые прототипы** (ChatGPT Canvas / код) — видно скролл и анимации. Медленнее.

Порядок работы: сначала вставляем **Базовый контекст**, потом по одному промпту направления. В конце — промпт «Лист компонентов», чтобы вытащить кнопки, карточки и переходы отдельно.

---

## 0. Базовый контекст (вставлять первым сообщением)

```
Ты — арт-директор топовой digital-студии (уровень Awwwards Site of the Day).
Мы проектируем лендинг студии контента полного цикла «Катализ» — студии компании
«Центр Бизнес Технологий». Студия делает любой контент: от полиграфии и упаковки
до роликов, интерактивных тренажёров, цифровых аватаров и сложного 3D-моделирования
(молекулы, анатомия, механизмы со сборкой/разборкой). Внутри — ИИ-конвейер, который
ускоряет производство в 2–4 раза, а сэкономленное время уходит в проработку деталей.

Главный слоган: «Точность в каждой детали».
Главная механика первого экрана: при скролле «тёмная материя» принимает разные образы:
облако → молекула → сердце → механизм (разлетается на детали и собирается) → продукт.
Аудитория — маркетинг и обучение в крупных компаниях (в основном фарма, но сайт
не должен выглядеть фармацевтическим). Язык сайта — русский.

Структура лендинга: hero со скролл-трансформацией → манифест → цифры →
4 направления (Визуал · Движение и 3D · Интерактив · Цифровые люди) →
как мы работаем (5 этапов конвейера) → кейсы → клиенты → стена форматов → контакт.

Не используй капсулы, таблетки, медицинские кресты, врачей и стоковые фото.
```

## 1–6. Направления (каждое — отдельным сообщением)

Для картинок добавлять в конце: `Сделай макет десктопного экрана 1440×900, вид спереди, без рамки браузера. Текст — крупный, минимум слов, на русском.`
Для кода: `Собери одностраничный прототип на HTML/CSS/JS с three.js, со скролл-анимацией hero.`

```
1. «Тёмная материя». Почти чёрный фон, облако из десятков тысяч светящихся частиц
в центре, которое при скролле складывается в молекулу, сердце, механизм.
Тонкая элегантная типографика, монохром + один холодный акцент. Покажи hero и
момент, когда частицы почти сложились в сердце.
```

```
2. «Точность в мелочах / Exploded view». Светлый инженерный стиль: тонкая
техническая сетка, чертёжные линии, размерные выноски, моноширинные подписи.
В центре — металлический механизм из 50 деталей в разобранном виде (exploded view)
с выносками «Шестерня Z=24 · допуск 0.01 мм». Один сигнальный цвет (оранжевый).
```

```
3. «Жидкий металл». Премиально и спокойно. Хромовая жидкая масса с радужными
отражениями на графитовом фоне перетекает из капли в молекулу и в механизм.
Крупный изящный антиквенный шрифт + чистый гротеск. Магнитная кнопка.
```

```
4. «Лаборатория». Светлый тёплый фон, кислотный лайм и фиолетовый акценты, строгая
швейцарская сетка, жирная гротескная типографика, научные пометки и нумерация.
Объект из сотен глянцевых шариков (clay render) собирается в молекулу.
Сбоку — панель-«показания прибора» с текущим этапом.
```

```
5. «Конвейер / завод». Брутализм: чёрный, молочный, горячий оранжевый.
Огромная узкая типографика капсом, бегущие ленты, таймер производства.
Hero — горизонтальный конвейер: блок тёмной материи едет через 5 станций и на
каждой превращается в новую форму. Счётчик «было 3 недели → стало 5 дней».
```

```
6. «Голограмма». Тёмно-синий космос, неоновые циан и маджента, HUD-интерфейс:
уголки-скобки, телеметрия, процент сканирования. Объект из тысяч светящихся
вокселей собирается в сердце, сканирующая плоскость проходит сквозь него.
```

## 7. Свободные направления (если хочется ещё)

```
Предложи ещё 5 принципиально разных концепций hero-блока для этого лендинга,
где «тёмная материя принимает разные образы» при скролле. Для каждой: название,
визуальный стиль, механика скролла, чем запомнится. Потом нарисуй макет лучшей.
```

## 8. Лист компонентов (для «солянки»)

```
По выбранному стилю [вставить название] нарисуй UI-kit на одном листе:
3 варианта основной кнопки (обычная / наведение / нажатие), вторичная кнопка,
карточка направления, карточка кейса, навигация, бегущая строка форматов,
индикатор прогресса скролла (01/05), форма контакта. Подпиши каждый элемент.
```

## 9. Сборка финала

```
Возьми из варианта [A] hero-механику, из [B] типографику и кнопки, из [C] карточки
кейсов и переходы между секциями. Собери единый лендинг в одном стиле и опиши
дизайн-систему: цвета (hex), шрифты, размеры, радиусы, анимации.
```
