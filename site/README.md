# Катализ — лендинг студии

Лендинг студии «Катализ» (студия Центра Бизнес Технологий). Направление дизайна — «Прозрачная система»:
светлый фон, тонкая сетка, стеклянные карточки, акценты синий `#246BFD` / фиолетовый `#8D5CFF` / бирюзовый `#20C7B7`,
шрифты Onest и IBM Plex Mono.

Стек: Vite + React 18 + TypeScript + Tailwind CSS 3, 3D — three.js + @react-three/fiber 8 + @react-three/drei 9,
анимации интерфейса — framer-motion. Структура совместима с Lovable.

```bash
npm install
npm run dev      # http://localhost:8080
npm run build    # сборка в dist/
npm run preview  # просмотр сборки
```

## Где что лежит

```
src/
  content.ts                 ← ВСЕ ТЕКСТЫ САЙТА (меню, заголовки, цифры, кейсы, форматы, контакты)
  index.css                  ← базовые стили, классы .glass-card, .label-mono, .section
  pages/Index.tsx            ← порядок секций на странице
  components/
    Header.tsx, Logo.tsx
    hero/                    ← первый экран и 3D-сцена
      Hero.tsx               ← разметка, «липкий» скролл, текст
      StageIndicator.tsx     ← шкала 01–04 и подпись состояния
      HeroScene.tsx          ← Canvas, свет (Lightformer), камера
      GlassStack.tsx         ← стеклянные пластины + логика сцен
      sceneConfig.ts         ← размеры пластин, углы, тайминги сцен
      ParticleField.tsx      ← частицы: облако → пластины → сетки (шейдер)
      Mist.tsx               ← мягкая «дымка» облака
      Lattice.tsx            ← объёмная решётка у 4-й пластины
      MicroWorld.tsx         ← микромир внутри последней пластины
      PlateShadow.tsx        ← мягкие тени под пластинами
    sections/                ← по одному файлу на секцию
      Manifesto, Stats, Directions, Process, Cases, Clients, Formats, Contact, Footer
    art/                     ← SVG-иллюстрации (иконки, направления, кадры кейсов)
    ui/                      ← Button, GridLines, SectionHeading, Reveal
tailwind.config.ts           ← цвета (mist, ink, brand, violet, teal), шрифты, тени
```

### Как поменять тексты
Откройте `src/content.ts` и правьте строки. Компоненты разметки трогать не нужно.
Цифры в блоке `stats` помечены как «ориентир» — уточните перед запуском.
Контакты (почта, телефон) — в `brand`, сейчас это заглушки.

### Кадры кейсов
Сейчас в карточках работ — процедурные SVG-«кадры» (`components/art/CaseArt.tsx`).
Когда появятся реальные стоп-кадры роликов, положите их в `public/cases/` и замените `<CaseArt />`
в `components/sections/Cases.tsx` на `<img src="/cases/имя.jpg" className="h-full w-full object-cover" alt="…" />`.

### Форма
`components/sections/Contact.tsx` — отправка пока не уходит в сеть (`preventDefault` + сообщение «Спасибо»).
Подключите свой обработчик (CRM, почта, бот) в функции `onSubmit`.

## Как работает 3D-hero

Секция hero высотой ~280vh, внутри — экран с `position: sticky`. Прогресс прокрутки внутри секции (0…1,
`useScroll` из framer-motion) управляет сценой из четырёх состояний (тайминги — `stageParams` в `sceneConfig.ts`):

1. **01 Облако** — рассеянное облако частиц и мягкой дымки.
2. **02 Форма** — облако конденсируется: частицы летят по дугам в стеклянные пластины, пластины вырастают.
3. **03 Система** — внутри пластин частицы выстраиваются: свободные → точечная сетка → объёмная решётка;
   в последней, толстой пластине проявляется микромир (нити «фибрина», красные клетки).
4. **04 Кадр** — пластины сдвигаются и выравниваются в один кадр, хроматическая аберрация уходит — кадр резкий.

Технические детали:
- Пластины — `RoundedBox` + `MeshTransmissionMaterial` (настоящее преломление, толщина, хроматическая аберрация).
  Для экономии сцена «за стеклом» рендерится **один раз за кадр** в общий буфер (`useFBO`), и все пластины
  преломляют его, вместо отдельного буфера на каждую пластину.
- Все частицы анимируются в вершинном шейдере (`ParticleField.tsx`) — на CPU только юниформы.
- Освещение — собственная «студия» из `<Environment><Lightformer/></Environment>`: ничего не скачивается из сети
  (пресеты drei тянут HDR с CDN, поэтому не используются).
- Лёгкий параллакс за курсором, плавное «догоняние» скролла.
- DPR ограничен (1.75 на десктопе, 1.5 на мобильных), на мобильных вдвое меньше частиц.
- Рендер останавливается, когда hero вне экрана (`IntersectionObserver` → `frameloop="never"`).
- `prefers-reduced-motion`: секция не закрепляется, сразу показывается финальный кадр, без анимации.
- Сцена грузится отдельным чанком (`React.lazy`) — текст первого экрана появляется сразу.

Чтобы изменить вид сцены: размеры/углы/расстояния — `sceneConfig.ts`; материал стекла — `GlassStack.tsx`;
цвета частиц — `ParticleField.tsx`; микромир — `MicroWorld.tsx`.
